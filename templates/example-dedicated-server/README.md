# Example Dedicated Server

This is a structure and validation example, not an installable game server.
Copy the directory, replace every example value, and remove this directory
before publishing the real catalog.

Document the following for each real template:

- Supported host architectures and game/server versions.
- Runtime and installer image provenance.
- Published and internal ports, protocols, and purposes.
- Startup variables and which values are secrets.
- Console command transport and test commands.
- Default backup selections and restore verification.
- Tested install, start, stop, restart, update, backup, and restore behavior.
